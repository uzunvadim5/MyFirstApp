**ЦЕЛЬ И ХОД ВЫПОЛНЕНИЯ РАБОТЫ**

Цель лабораторной работы — установить .NET SDK, проверить доступность инструмента dotnet в командной строке, создать консольные проекты на языке C# и выполнить их.

В ходе работы были выполнены следующие задачи:

установлен .NET SDK версии 10.0.403;

проверена работа команды dotnet --version;

создан первый проект вручную с файлами Program.cs и MyFirstApp.csproj;

создан второй проект с помощью команды dotnet new console;

выполнена компиляция и запуск обоих проектов командой dotnet run.

**1. Установка и проверка .NET**

После установки .NET SDK была открыта новая командная строка Windows и выполнена команда:

**dotnet --version**

Команда вывела номер версии 10.0.403. Это подтверждает, что .NET SDK установлен и команда dotnet доступна для выполнения.

![](images/image1.png)

*Рисунок 1 — Проверка установленной версии .NET SDK*

**2. СОЗДАНИЕ ПЕРВОГО ПРОЕКТА ВРУЧНУЮ**

Для первого проекта была создана папка MyFirstApp на рабочем столе. В ней вручную созданы два файла: Program.cs — файл исходного кода программы, и MyFirstApp.csproj — файл конфигурации проекта.

В файл Program.cs был добавлен следующий код:

using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, World!");
    }
}

В файл MyFirstApp.csproj добавлена конфигурация проекта с типом приложения Exe и целевой платформой net10.0:

<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>
</Project>

После перехода в каталог проекта была выполнена команда dotnet run. Проект успешно скомпилировался и запустился, а в консоли появилось сообщение Hello, World!.

![](images/image2.png)

*Рисунок 2 — Успешный запуск первого проекта MyFirstApp*

**3. СОЗДАНИЕ ВТОРОГО ПРОЕКТА С ПОМОЩЬЮ .NET CLI**

Для проверки автоматического создания проекта была использована команда dotnet new console -n SecondApp. Она создала папку SecondApp, файл проекта SecondApp.csproj и исходный файл Program.cs. После создания .NET выполнил восстановление необходимых зависимостей.

Затем был выполнен переход в папку второго проекта командой cd SecondApp и запуск программы командой dotnet run.

В результате программа успешно выполнилась и вывела в командной строке сообщение Hello, World!. Таким образом, автоматическое создание и запуск консольного проекта также прошли успешно.
