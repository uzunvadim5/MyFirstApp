**ЦЕЛЬ И ХОД ВЫПОЛНЕНИЯ РАБОТЫ**

Цель лабораторной работы — изучить структуру базового проекта .NET, понять назначение папок bin и obj, проверить процесс компиляции и запуска программы, а также освоить базовые инструкции и функции языка C#.

В ходе лабораторной работы были выполнены следующие задания:

удалены папки bin и obj и проверен запуск программы без компиляции;

выполнена повторная компиляция проекта с помощью команды dotnet build;

найден и запущен исполняемый файл проекта;

добавлена инструкция Console.ReadKey() для ожидания нажатия клавиши;

созданы и вызваны функции для вывода текста A, B, C;

изучены порядок выполнения инструкций и правила определения и вызова функций.

**1. Компиляция и исполняемый файл**

Сначала была открыта папка проекта MyFirstApp. Для удаления результатов предыдущей сборки были выполнены команды:

rmdir /s /q bin
rmdir /s /q obj

После удаления папок была выполнена команда dotnet run --no-build. Программа не запустилась, так как команда --no-build запрещает повторную компиляцию, а исполняемый файл в папке bin был удалён.

**2. Повторная компиляция и запуск программы**

Для восстановления файлов проекта была использована команда:

dotnet build

Сборка завершилась успешно. В папке bin\Debug\net10.0 был создан результат компиляции. Затем исполняемый файл был запущен непосредственно из командной строки:

bin\Debug\net10.0\MyFirstApp.exe

В результате в консоли появилось сообщение Hello, World!. Это подтвердило, что программу можно запустить непосредственно из созданного исполняемого файла.

**4. Базовые инструкции и функции**

В следующей части работы была создана программа, которая выводит сообщение Hello, Jerry, а затем три раза печатает буквы A, B и C. Между выполнениями добавлена задержка 500 миллисекунд с помощью Thread.Sleep(500).

Также были созданы три функции: A, B и C. Функция A вызывает функции B и C. В основной части программы функция A вызывается три раза.

Основные фрагменты использованного кода:

Console.WriteLine("Hello, Jerry");

PrintABC();
Thread.Sleep(500);
PrintABC();
Thread.Sleep(500);
PrintABC();

A();
A();
A();

void PrintABC()
{
    Console.WriteLine("A");
    Console.WriteLine("B");
    Console.WriteLine("C");
}

void A()
{
    Console.WriteLine("Function A");
    B();
    C();
}

void B()
{
    Console.WriteLine("Function B");
}

void C()
{
    Console.WriteLine("Function C");
}

После запуска программа корректно вывела Hello, Jerry, три последовательности A, B, C, а также результаты трёх вызовов функции A вместе с вызовами B и C.

**5. Теоретические наблюдения**

Папка bin содержит результаты компиляции, в том числе файлы, необходимые для запуска приложения.

Папка obj содержит промежуточные файлы, используемые при сборке проекта.

Команда dotnet build выполняет компиляцию проекта.

Команда dotnet run запускает проект и при необходимости предварительно компилирует его.

Команда dotnet run --no-build запускает проект без предварительной компиляции.

Функция — это именованный блок кода, который выполняет определённые действия при вызове.

Если функция нигде не вызвана, её инструкции не выполняются.

В C# функция может вызывать другую функцию, определённую ниже в файле; порядок расположения определений функций не является обязательным.
