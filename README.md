# MyFirstApp

Лабораторные работы по дисциплине «Cloud» (.NET / C#).

- Лабораторная работа 1 — установка .NET SDK, создание консольного проекта вручную и через `dotnet new console`.
- Лабораторная работа 2 — основы функций и многократных вызовов в C#.

## Запуск

```powershell
dotnet run
```

Требуется .NET SDK 10.0.
